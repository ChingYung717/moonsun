# 天体贴图版权与来源说明 (Texture Credits)

本项目使用的天体表面贴图来自公开科学数据与开源天文可视化资源：

1. **地球昼面 / 夜面灯光 / 云层 / 高光法线贴图 (Earth Day, Night, Clouds, Specular, Normal)**
   - 来源：NASA Visible Earth (Blue Marble Next Generation / Black Marble) & Three.js Planetary Textures
   - 许可：NASA Public Domain (公有领域) / CC BY 4.0

2. **月球表面彩色与高程贴图 (Moon Color & Displacement Map)**
   - 来源：NASA Scientific Visualization Studio (CGI Moon Kit, LRO LROC WAC + LOLA)
   - 许可：NASA Public Domain (公有领域)

3. **太阳表面与银河星空背景 (Sun & Milky Way Starfield)**
   - 来源：Solar System Scope (INOVE) / ESO / NASA
   - 许可：CC BY 4.0 (Attribution 4.0 International)
